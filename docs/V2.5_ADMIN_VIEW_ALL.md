# Admin view-all and assigned editing

Admin and Super Admin may view every Goal, Indicator, Initiative and reporting record, including Private=Yes items. Private limits public visibility only. Admins may still edit or upload reporting data only for resources allowed by Goal assignments and explicit resource subsets. Master definitions and names remain Super Admin-only.

The existing authenticated Admin snapshot now returns all master/reporting rows and a separate editable resource-ID list. The UI uses that list to disable master Edit links and keep unassigned table cells read only. Upload name matching is restricted to editable masters. The existing server-side can-manage checks still authorize every write and reject unauthorized batches atomically. Revision checks are retained. No new table or column is introduced.

The Admin overview shows assigned Goal, Indicator and Initiative counts. Its Your assigned goals section filters by the signed-in user's explicit Goal memberships; it does not reuse the full read-only Goal list. Indicator and Initiative counts use the API's editable resource IDs so child restrictions are respected. Admin1 (id 6) was verified read-only to have Goal G2, Indicator ID4 and Initiatives IN6/IN7 at the time of this fix. All-record viewing remains available in the configuration pages. The fix changes no stored assignments or reporting records. Validation: seven assignment regression tests and React build passed.

Both sign-in pages use a dark background and logo. Signed-in workspaces retain the independent light-default theme preferences added previously. Version and Powered by footer remain visible.

New or renamed master names must be unique within each entity type throughout the district, ignoring case and repeated whitespace. This is enforced inside the authenticated Super Admin save transaction, under its existing advisory lock. Existing unchanged legacy duplicates remain readable and do not block unrelated edits; they must be renamed explicitly. Admin users cannot rename masters.

IN1 and IN5 previously had identical full names and short names. IN1 is Private=Yes. At the user's request, IN5 was renamed to “Implement differentiated instruction, evidence-based teaching routines, and a rigorous core curriculum to meet the learning needs of all students.” with short name “Advance Differentiated Instruction”. Both its master and linked reporting names were updated in one transaction. A checksum verified that the 12 action items and all reporting fields other than Initiative Name were unchanged. IN5 remains public.

Validation: React build; 28 focused API tests; existing Node regression tests; real PostgreSQL Super Admin and Admin transactions including duplicate-name rejection, all-record read access and assigned-only editing. Database regression fixtures are rolled back. Public master query for G1 returns IN2, IN3 and IN5, excluding private IN1. Production frontend is not redeployed.

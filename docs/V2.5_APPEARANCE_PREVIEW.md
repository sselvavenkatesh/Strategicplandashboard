# V2.5 Appearance preview

Appearance is available in the administration navigation. Super Admin can adjust the Welcome brand, Goal/Mission/Vision accents, Goals position, Mission/Vision position and two bundled landscape wallpapers. Ordinary Admin controls are view-only. Conflicting side placements move the other section below to avoid overlap. The mobile layout stacks sections.

Use Green template, then Apply & preview. A direct green example is available at the Welcome URL with ?appearance=green. Custom preview uses ?appearance=custom and versioned, validated browser settings. Existing Welcome stays unchanged without either preview parameter. Settings are preview-only, not saved to the database or shared across browsers. Reset removes the local preview settings. No district data, API permissions, SSO credentials or production deployment changes are involved.

The green template uses Goals on the right and Mission/Vision below, with a bundled emerald woodland illustration. All existing Goal buttons and Explore links retain navigation to Summary. The existing model/data access is reused.

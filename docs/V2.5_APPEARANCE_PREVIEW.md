# V2.5 Appearance preview

The Appearance section offers Goals right/bottom, Mission/Vision right/bottom, and statement order. Side placement automatically swaps the other section to prevent overlap. Color and wallpaper controls are removed; district branding will be decided separately. Welcome wording and typography follow the existing Welcome design and stay on the left. Only the supporting Goal and Mission/Vision sections swap.

Super Admin can apply browser-only previews; Admin has view-only controls. No database writes or production changes occur. The existing green example remains at ?appearance=green; custom previews use ?appearance=custom. Mobile sections stack. Settings are not yet saved to the database.

Layout previews reuse the original Welcome goal-card and Mission/Vision card classes, including their dark/light theme colors, borders, hover states and goal icons. Position settings change layout only. The existing Welcome background overlay is retained.

## Configuration and API cutover

React uses FastAPI exclusively. The browser Supabase SDK, direct REST/RPC/Auth path, old Super Admin route and Edge Function fallback were removed. Supabase remains PostgreSQL and Vault. Netlify transports requests to FastAPI; FastAPI retains identity, authorization, DB and AI logic.

The owner explicitly approved the Free-plan default secret scopes Builds, Functions and Runtime in both Netlify projects. Matching proxy keys are encrypted/masked, are configured for production/previews, and are not placed in Git or client-prefixed variables. Functions-only scoping required an upgrade; the supported Free setting resolved the earlier 403. The Vercel backend was explicitly authorized and redeployed to activate its matching setting.

After publication, the browser Data API grants were retired transactionally. The cutover preserves the backend's existing effective function/table permissions, including helper functions used by security-invoker views, and automatically aborts if those effective privileges change. Browser roles have no public-table grants or public-function EXECUTE. No reporting rows, users, passwords or Vault keys were changed. The revised script is in supabase/cutover/v25_retire_browser_api.sql.

Legacy district-ai, district-ai-preview and log-dashboard-access Edge Function deployments now return HTTP 410 retirement responses instead of running their former logic. JWT verification settings were preserved. The common retirement implementation is in supabase/retired-edge-functions/index.ts; original function source remains historical parity evidence, not deployed runtime logic.

## Remaining boundaries

Appearance remains a browser-only preview rather than district-wide DB persistence. Multi-district schema/session isolation and installer provisioning are separate future work. Operational MFA, retention decisions, full historical secret/IAM review and a backup-restore exercise remain tracked in the architecture review. Public AI remains model-generated and requires validation of its wording. A passing build is not a penetration-test certification. Netlify branding is visible on the current Free-plan publication.

For recovery, preserve V2.4 source history and this publication record. Old V2.4 browser API clients are intentionally retired: re-publishing that frontend alone will not restore its DB/Edge Function access. A recovery change must explicitly restore the required old permissions/endpoints or fix V2.5 forward.
